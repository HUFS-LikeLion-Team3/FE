# 데스크톱 학습 흐름과 API 연동

최신 범위는 뉴스 상세·관찰 대상 선택/변경·예측 작성과 제출·최초 피드백·결과/중간 메모·최종 회고·최종 피드백·완료 타임라인·관심 설정 변경이다. 로그인·최초 관심 설정은 기존 구현을 재사용하며 홈·학습 기록 보완과 함께 dev에 병합됐다. 뉴스 탐색은 [별도 기능 문서](../explore/README.md)를 따른다. 모바일 전용 UI는 후속 범위다.

## 경로

- `/news/:newsId`: 뉴스 상세와 세션 상태별 진입.
- `/news/:newsId/predict`, `/learning/:sessionId/edit`: 대상 선택/변경 → 예측 작성 → 제출 검토. 선택을 URL로 넘길 때는 `?targets=시장대상UUID,...`를 사용한다. 알 수 없는 ID를 임의 대상으로 바꾸지 않는다.
- `/learning/:sessionId/feedback`: 최초 AI 피드백.
- `/learning/:sessionId/results`: 기준값·1/5/20거래일 결과·시계열·수집 이력·1/5일 메모.
- `/learning/:sessionId/reflection`: 최종 회고. 질문 하나 이상을 작성하고 저장한다.
- `/learning/:sessionId/final-feedback`: completed 이후 최종 AI 피드백.
- `/learning/:sessionId`: completed 세션의 다섯 단계 타임라인과 읽기 전용 기록.
- `/settings/interests`: 저장된 관심사 변경. 온보딩 완료 요청은 보내지 않는다.

## 실제 API와 개발용 목

기본값은 실제 HTTP API다. 실행·환경 변수·카카오 콜백은 [루트 README](../../../README.md#시작하기)와 `.env.example`을 따른다. 로컬 포트나 특정 실행 서버를 고정된 현재 상태로 가정하지 않는다.

`VITE_MOCK_LEARNING_API=true`를 명시하면 개발에서만 목 모드를 사용한다. `/dev/flow`에 진입해도 현재 탭의 개발용 목 모드가 명시적으로 켜진다. '실제 API 모드로 돌아가기'로 종료한다. 목 모드는 뉴스·대상·세션·예측·결과·회고를 메모리에서 처리하며 새로고침 시 초기화된다. 모의 관측값과 AI 결과를 실제 데이터라고 표시하지 않는다. 실패한 HTTP 요청을 목 성공으로 바꾸지 않는다. 배포 빌드에는 목 구현과 데모 데이터가 들어가지 않는다.

`/dev/pages`는 기존 네 페이지의 UI 상태 미리보기다. `/dev/flow`는 신규 입력·저장·관측·회고 흐름과 대기/부분 완료/관측 불가/최종 AI 실패 시나리오를 제공한다.

## 입력과 저장

대상별 입력은 시장 대상 ID를 키로 보관한다. 선택 해제 후 재선택과 단계 전환에서 입력을 유지한다. 진입/단계 이동은 저장하지 않고 첫 임시 저장 또는 제출에서만 세션을 생성한다. 세션 ID와 시장 대상 ID/세션 대상 ID 매핑을 유지해 재시도에서 중복 생성을 줄인다.

세션 생성 → 선택 대상 저장 → 각 대상의 예측 저장이 모두 성공해야 제출한다. 일부 저장 실패와 제출 응답 유실에서 입력을 보존하고 서버의 상태를 다시 확인한다. 성공한 전체 저장만 마지막 저장 상태를 갱신한다. 서버에 저장한 선택 해제 대상의 예측도 읽어 재선택 시 복원한다.

메모는 해당 기간 관측이 ready 또는 unavailable인 경우만 추가한다. 최종 회고는 서버의 reflection_pending에서만 작성한다. 최종 회고 저장 응답의 completed와 clientRequestId를 확인한 뒤 최종 피드백으로 이동한다. 같은 내용의 실패 재시도에는 같은 clientRequestId를 사용한다. 최종 저장 응답 유실은 해당 ID의 저장된 메모를 다시 조회해 복구한다. 완료 상태와 AI 생성 실패를 분리한다.

## 데이터 표시와 캐시

결과 화면은 BE의 baseline/observations와 실제 series를 사용한다. FE 날짜로 T0나 관측 종료를 추정하지 않는다. 미래 종가를 만들지 않으며 빈 시계열·대기·관측 불가·지연을 구분한다. 금리의 `%` 단위 변화량은 퍼센트포인트이며 표시할 때 100을 곱해 bp로 변환한다.

시계열 경로는 실제 BE의 `/learning-sessions/{id}/targets/{targetId}/series`, 수집 이력은 `/session-targets/{targetId}/outcome-events`를 따른다. API 응답의 세션/대상 ID를 소비 위치와 대조한다. 뉴스 API에 없는 배경 맥락·용어·원문 출처를 만들지 않는다. 대표 출처는 isPrimary 자료로 표시한다. AI 재생성 API가 없어 임의 요청을 추가하지 않는다.

401은 토큰을 제거하고 로그인을 안내한다. 로그인·로그아웃은 QueryClient 캐시를 비워 사용자 간 기록이 섞이지 않게 한다. 로그인 후 안전한 앱 내부 returnTo로 복귀한다. 관심사 저장은 관심사 캐시를 갱신하고 추천 뉴스 캐시를 무효화한다. 홈은 상태별 최신 세션을 우선순위 순서로 조회하고, 학습 기록은 서버 상태 필터와 페이지 추가 조회를 사용한다. 추가 조회 실패에서도 이미 읽은 기록은 유지한다.

## 검증과 한계

lint·build·diff 검사와 브라우저 대역/개발 목으로 입력 유지, 저장·제출 실패, 초안 재진입, 메모·회고, 완료 기록, 관심 설정 재조회 실패를 검증했다. 실제 인증된 전체 저장·외부 시장 수집·운영 AI 생성 완료를 의미하지 않는다.

개발 목은 명시적으로 켜며 실제 HTTP 오류의 대체 성공 응답으로 사용하지 않는다. 환경·DB·브랜치·PR의 날짜별 작업 이력은 이 사용 문서에 누적하지 않는다.
